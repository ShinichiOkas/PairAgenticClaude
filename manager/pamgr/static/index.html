判断待ち

師匠の判断が要るものだけが、ここに上がります（同時に効く規則の矛盾・マージできない変更・管理に入れるかの確認・ほかのユーザーの規則）。それ以外は自動で片づけ、「自動でやったこと」に載せます。

自動でやったこと

点検が自動でやったこと（配る・マスターへ取り込む・一般化・管理に入れる）の時系列です。違っていれば取り消せます。通知はしません。

効いている規則

あるプロジェクトのエージェントが同時に読む規則の全部（全体＋ユーザー固有＋そのプロジェクト）を、出所つきで見ます。矛盾の検査はこの集合の中で行います。

管理下（PC・プロジェクト）

この PC

.pair-agent/ を持つプロジェクトは自動で管理下に入ります。持たないもの（他人のリポジトリかもしれない）は「判断待ち」で確かめます。外したものは二度と聞きません。

ほかの PC・ほかのユーザー（GitHub）

各 PC が取り込んだ変更をマスター（このリポジトリ）に commit・push し、ほかの PC は pull して同じ流れで配ります。

検査（矛盾・冗長）

冗長は機械（文字の類似）で検出。矛盾は類似の組を LLM が判定し、「状況次第で両方真」なら状況を提案する。LLM の判定はすべて仮説として出す（資産は書き換えない）。

状況定義

矛盾して見える 2 つの指示が、別の状況ではそれぞれ真になることがある。その「状況」を名前と定義で登録する。検査の LLM はこの一覧を参照して判定する。
