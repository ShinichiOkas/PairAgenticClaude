# 修正内容の確認 - Windows環境対応

Windows 11環境でも `Pair Agent` を利用できるように、インストールスクリプトの移植とドキュメントの更新を行いました。

## 変更内容

### 1. `install.bat` の新規作成
`install.sh` と同等の機能を持つ Windows 用バッチファイルを作成しました。
- **フルインストール**: `%USERPROFILE%\.claude` への各コンポーネントの配置。
- **プロジェクト導入**: `install.bat --project` によるカレントディレクトリへの設定配置。
- **アンインストール**: `install.bat --uninstall` による関連ファイルの削除。
- **リッチなログ出力**: PowerShell を介して ANSI エスケープ文字を取得し、色付きのログ出力を実現しました。
- **堅牢な構造**: `GOTO` とラベルを使用することで、複雑な条件分岐でも安定して動作するように設計しました。

### 2. `README.md` の更新
Windows 環境での利用手順を追加しました。
- インストールセクションへの `install.bat` の追記。
- プロジェクト導入コマンド例の追加。
- アンインストール手順の追加。
