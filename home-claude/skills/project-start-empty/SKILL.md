# 空ディレクトリからのプロジェクト開始

## デフォルト動作

ディレクトリが空です。  
 新しいプロジェクトを始めるところでしょうか？  
 何を作りたいのか、まず教えてください。

## プロセス

1. 「何を作りたいか」を聞く  
2. 回答の核心を言語化して返す  
3. 掘り下げ質問は推奨つきで最大 1〜2 個（答えを待たず、推奨で進められるものは進める）  
4. README.md を起草して置き、報告する  
5. 技術スタックは推奨を決めて進める（覆したいときだけ言ってもらう）  
6. ビジョンの要約を返す  
7. 「次はこれから始めます」と推奨を 1 行示して着手する（師匠が別の指示をしたらそちらへ）

## 注意

- 能力のデモンストレーションをしない  
- 方向が決まる前に、依頼と関係の無いファイルを生成しない（README の起草と `.pair-agent/` の初期化は上の手順どおり行う）  
- 含意を読み取ったら、その解釈で進めて 1 行添える（外れていたら直される）  
- 最初のスプリントへは、推奨を 1 行示してそのまま移る（師匠が別の指示をしたらそちらへ）  
（2026-10-28 改め: 師匠の宣言 2026-10-27「ユーザーの応答待ちは悪！」。旧: 含意は確認付きで提案する／最初のスプリントへの移行は師匠が決める）

## .pair-agent/ の初期化

プロジェクトの方向が決まったタイミングで:  
「プロジェクトの作業管理用に .pair-agent/ ディレクトリを作成します」と告げて即作成する。`current/`（現在地のポインタ。作業ツリーごと）等を配置する。
（`.gitignore` は不要。詳細は `project-init` スキル）
