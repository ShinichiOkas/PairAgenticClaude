層状設計では、**1層 = 1ファイル**に収める。`l0.py` / `l1.py` / `l2.py` … と、層番号がそのままファイル名になる。

**Why:** 師匠の明示宣言 —— 実装を見て「1ファイルに収まっているのがとても良い。これをこのプロジェクトの原則ルールにしよう」。ミニマルさ（機構の薄さ・概念の少なさ）を、ファイル構造のレベルで体現する。**1ファイルで層全体を一望できること**を優先する。

**How to apply:**

- 新しい層を作るときはファイルを1つだけ作る。層を複数ファイルに分割しない
- 1ファイルに収まらなくなったら、それは「層が厚すぎ／責務を持ちすぎ」のシグナル。**ファイル分割より先に、層の責務を見直す**
- テストも層ごとに1ファイル（必要なら実接続用を別に1つ）
