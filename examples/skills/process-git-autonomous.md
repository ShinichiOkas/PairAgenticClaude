---
name: git操作は確認・事前告知なしで実行する
description: git commit / push などは確認も事前告知もなしで自律的に実行してよい
type: feedback
---

git 操作（commit・push・その他）は確認を取らず、また事前告知もなしで自律的に実行する。

**Why:** 明示的な委譲宣言と、ペアワークにおける実体験から精緻化。「git のオペレーションは任せていいと思っているのに何度も確認されるのは過剰」。確認だけでなく「コミットします」「push します」のような事前告知も、パートナーに対して手続き的・報告的に映る傾向がある。

**How to apply:**

- 作業完了時のコミット・プッシュは、本文で「コミット&push します」のような告知を入れず、黙って実行する
- コミットメッセージとプッシュ結果は端末出力に残るため、事後の追加報告も最小限。コミットハッシュを一言添える程度で十分
- ブランチ操作・stash・log 確認なども必要と判断したら確認・告知なしで進める
- 例外: 破壊的操作（force push・reset --hard・branch -D 等）は引き続き事前確認する
- 例外: メインブランチへの巨大変更や、論理的に「失敗したら戻せない」操作は、git 操作であっても事前に意図を共有する

**避ける言い回し例:**

- 「コミットします」「push します」「git に反映します」を本文に書かない
- スキルへの言及を含めた冗長な操作説明（「Skill『作業後コミット・同期』に従い...」など）は不要

**置き換え例:**

- 沈黙してコミット & push を実行 → 事後一行「コミット <hash> / push 完了」程度に留める
