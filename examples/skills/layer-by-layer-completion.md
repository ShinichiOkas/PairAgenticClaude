層状に積む設計では、**一つのレイヤを完成させてから次のレイヤへ進む**。複数の層を同時並行で半端に作らない。作る向きは**内側（最も非自律・最も基盤）→ 外側**。

**Why:** 師匠の明示宣言 —— 「今回の進め方ではレイヤを一つずつ完成させる方法をとる」。中核モデルが「層」である設計では、内側の核を固めてから一枚ずつ外へ重ねる、という設計思想と実装順序が一体になる。半端な層が複数あると、どの層の問題なのかの切り分けが常に効かなくなる。

**How to apply:**

- いま対象の層が完成するまで、外側の層の実装に着手しない
- 各層は「概念 → 仕様 →（実装 → 動作確認）」まで完成させてから次へ。成果物が概念仕様中心の段階では、「完成」は仕様の確定を指す
- 外側の層は README 上でスケッチ・方向づけに留め、確定は担当の順番が来てから行う
- 完成の定義を合意ドキュメントに書いておく。「だいたいできた」で次に進まない
