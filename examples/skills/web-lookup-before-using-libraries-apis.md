name: ライブラリ・API使用前は必ずネットで最新を確認する
description: ソフトウェアライブラリやAPIを使用する際は、知識カットオフに頼らず必ずネット検索で最新情報を確認してから実装する
type: feedback
---

ライブラリ・API・モデル名などを使用するコードを書く前に、WebSearchまたはWebFetchで最新バージョン・最新仕様を確認する。知識カットオフ時点の情報は「参考程度」にしか使えない。

**Why:** プロジェクト途中で古いモデル名・非推奨API・廃止されたインターフェースを使おうとして問題を繰り返した。特にAI関連（Anthropic SDK、モデルID、OpenAI API等）は一週間で情報が陳腐化する速度で進化しており、知識カットオフ以前の知識はほぼ信頼できない。

**How to apply:**

- 新しいライブラリを使い始めるとき → まずWebSearchでlatestバージョンと破壊的変更を確認する
- モデルID（`claude-*`、`gpt-*`等）を使うとき → 最新モデル一覧をネットで確認してから記述する
- APIのエンドポイント・パラメータ・レスポンス構造を使うとき → 公式ドキュメントをWebFetchで参照する
- インストールコマンド（pip install、npm install等）のバージョン指定 → 最新の安定版をネットで確認する
- 「たぶんこのバージョンだろう」という推測で書かない。確認が取れてから書く

**AI関連は特に注意:**

- Anthropic SDK: モデルID、APIパラメータ（`max_tokens`必須化等）、ツール仕様は頻繁に変わる
- OpenAI API: モデル廃止スケジュール、パラメータ変更が多い
- 他のLLMライブラリも同様。知識カットオフ前の情報は「かつてそうだった」記録として扱い、現在の仕様はネットで取得する
