Windows コンソールの既定コードページは **cp932**。ターミナルやログファイルへのデバッグ出力では文字種に注意する。

**避ける（cp932 で文字化け・`UnicodeEncodeError`）:**

- 罫線素片: `┌` `│` `└` `─` など
- 絵文字: `🎯` `✅` `➕` `📋` `✓` など

**使える:**

- ASCII 記号での枠（`=` `-` のリピート、インデント）
- 日本語・全角記号（`『』` `（）` など cp932 に含まれるもの）

**Why:** ログブロックの初版で罫線＋絵文字を使い、cp932 端末で全面文字化けした。ASCII 枠に変えて解決。**日本語本文自体は cp932 で問題なく出る**（化けたのは罫線・絵文字だけ）。

**How to apply:**

- 人間可読なログブロックは `_RULE = "=" * 52` のような ASCII 区切りで囲む
- **表示用と保存用を二面で持つ**: 永続化する監査ジャーナル（jsonl 等）は `encoding="utf-8"` で書き、記号の制約を受けずに完全保持する。表示用＝ASCII 安全、保存用＝UTF-8 完全
- 検証時にスクリプトから出すなら `PYTHONIOENCODING=utf-8` を付ければ端末でも崩れずに確認できる
- CLI の入出力も同様に UTF-8 に揃える（→ [[per-layer-touchable-cli]]）
